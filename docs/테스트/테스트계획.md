## 0. 이번 QA 의 중심 질문

**"제품의 선순환 루프가 실제로 한 바퀴 도는가."** 단위 테스트 통과가 루프가 돈다는 증명은 아니므로, 스케줄러가 실제 DB 위에서 시간 축을 따라 단계를 전이시키고 데이터가 이음매를 건너 흐르는지를 **가상 시계로 4주를 돌려** 직접 확인한다.

```
설정값 → 주간 식단 자동 생성(활성 사용자) → 주문 초안 → 1탭 승인/그레이스 자동확정
  → delivery_eta 시점 냉장고 자동 등록 → 조리·식사 완료 자동 차감
  → 냉장고 잔여·임박 재료가 다음 식단 입력에 반영 → 잔여분만큼 다음 주문 감산 → (반복, 월 예산 한도 누적)
```
