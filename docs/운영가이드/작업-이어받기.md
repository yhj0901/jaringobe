## 3. 로컬 환경 세우기

상세는 [install-guide.md](./install-guide.md) / [backend-portable-guide.md](./backend-portable-guide.md).

```bash
cp .env.example .env
# JWT_SECRET 채우기: openssl rand -hex 32
docker compose up -d --build      # db + backend, 마이그레이션 자동 적용
curl http://localhost:8000/health # {"status":"ok","db":true,...}

cd frontend && npm install
echo "BACKEND_URL=http://localhost:8000" > .env.local
npm run dev
```

**포트 주의**: 원래 개발 머신에서는 5432/8000 을 다른 프로젝트가 점유해 `.env` 에
`POSTGRES_PORT=5433` / `BACKEND_PORT=8001` 을 썼다. 새 머신에서 포트가 비어 있으면
`.env.example` 기본값(5432/8000)을 그대로 쓰면 된다. 바꿀 경우 `DATABASE_URL` 과
`TEST_DATABASE_URL` 의 포트, `frontend/.env.local` 의 `BACKEND_URL` 도 같이 맞춘다.

## 5. ★ 이어받는 사람이 가장 먼저 볼 것 — 미해결 결함 8건

`/code-review` 가 `origin/main..feature/loop-cycle-base` 전체를 리뷰해 나온 것이다.
**아직 아무것도 고치지 않았다.** QA 전에 처리하는 것을 권한다.

### 직접 확인된 심각 2건

**① 예산 한도 계산 오류 — 루프가 한 주 만에 멈춘다** · `backend/app/domains/budget/service.py:64~85`
```python
share     = prorate(월예산, cycle_start ~ +cycle_days)   # ≈ 월예산 × 7/31
committed = SUM(cycle_start 소속 월 전체의 confirmed 주문)
return max(0, share - committed)
```
1주차는 정상이나 주문 한 건이 확정되면 `committed ≈ share` 가 되어 **2주차부터 한도가 0**.
예산 락 사용자는 남은 달 내내 `BUDGET_EXCEEDED` 로 자동주문이 막힌다.
`docs/설계/architecture.md` 3-9-4 의 수식도 동일하므로 **설계와 구현을 함께 고쳐야 한다.**

**② 레이트리밋 회귀 — 사이클 작업이 기존 방어를 약화시켰다** · `backend/app/domains/order/router.py:39~43`
```
자동주문 P0: /preview 에 무조건 레이트리밋
현재      : if refresh and not ... → refresh 아니면 무제한
```
`/preview` 는 네이버 5페이지 조회 + LLM 선택을 부르고 회원 홈 마운트마다 호출된다.
지금은 제한 없이 외부 API 비용이 나간다.

### 설계 문서에 반영해야 할 갭 3건
- `CycleState` 에 배송 완료/전체 수가 없어 프론트가 수치를 못 보여준다 (합의: 일반 진행 문구)

- `orders.confirmed_at` DROP NOT NULL 이 `db-schema.md` 확장 목록에서 누락 (구현은 0011 에서 해소됨, 문서 미반영)

### 보안 점검 항목 (QA 이관)
`GET /orders/preview?refresh=true` 는 GET 인데 초안을 갱신 저장한다. 백엔드 Origin 검증은
`POST/PUT/PATCH/DELETE` 에만 걸려 있어(`main.py` `_STATE_CHANGING_METHODS`) 이 경로는 CSRF
방어를 우회한다. 리미터 3회/분이 있고 영향이 "자기 초안 재계산"이라 심각도는 낮지만 점검 대상이다.

### 롤백 위험
`0011`/`0012` 의 downgrade 는 **파괴적**이다. 0009 계약을 복구하려고 비-confirmed 주문과
연관 `order_items` 를 삭제하고, 신규 알림 설정 행 삭제·`delivery` 소스를 `order` 로 되돌린다.
운영 DB 에서 함부로 downgrade 하지 마라.

## 7. 배포 상황 — 백엔드는 로컬에서 돌린다

요금 문제로 상시 백엔드 서버(`api.jaringobe.cloud`)를 내렸다. **백엔드는 로컬 docker 로 돌리는 것이 현재 정본이다.**

### 개발은 전부 로컬로 완결된다 — 터널이 필요 없다

3장대로 하면 백엔드·DB·프론트가 전부 로컬에서 돌고 외부 의존이 없다.

```
브라우저 → localhost:3000 (Next.js) → rewrites 프록시 → localhost:8000 (FastAPI) → localhost:5432 (postgres)
```

검증된 동작: 게스트 홈 200 / API 프록시 401(정상) / 소셜 로그인 authorize 302.
**개발·테스트만 할 거라면 이 장의 나머지는 읽지 않아도 된다.**

### 터널은 "Vercel 프론트를 쓸 때만" 필요하다

`https://jaringobe.cloud` (Vercel) 는 인터넷에 있고 로컬 백엔드는 `localhost` 라 서로 닿지 않는다.
현재 Vercel 프론트는 정적 화면(`/ko`)은 200 이지만 **API 는 전부 502** 다 — `BACKEND_URL` 이
사라진 백엔드를 가리키기 때문이다. 이걸 살리려는 경우에만 터널이 등장한다.

| 상황 | 터널 |
|------|------|
| 내 PC 에서 개발·테스트 | **불필요** |
| 팀원/외부에 시연 | 필요 |
| Vercel 프론트를 살려야 함 | 필요 |

터널이 필요하다면 두 방식이 있다.

1. **임시 (quick tunnel)** — 계정 불필요, 1분.
   ```bash
   cloudflared tunnel --url http://localhost:8000
   ```
   출력된 `https://xxxx.trycloudflare.com` 을 Vercel `BACKEND_URL` 에 넣고 재배포.
   **프로세스가 죽으면 URL 이 바뀌어 Vercel 을 매번 다시 고쳐야 한다** (실제로 두 번 죽었다).

2. **고정 (named tunnel)** — `api.jaringobe.cloud` 고정 주소. 도메인을 이미 보유하고 있어 추가 비용 없음.
   첫 단계가 브라우저 로그인이라 사람이 직접 해야 한다.
   ```bash
   cloudflared tunnel login          # 브라우저가 열림 → Cloudflare 계정 로그인 → 도메인 선택
   cloudflared tunnel create jaringobe-api
   cloudflared tunnel route dns jaringobe-api api.jaringobe.cloud
   cloudflared tunnel run --url http://localhost:8000 jaringobe-api
   ```
   이후 Vercel `BACKEND_URL` 을 `https://api.jaringobe.cloud` 로 **한 번만** 넣으면 끝난다.

터널을 쓸 때는 백엔드 `.env` 를 `FRONTEND_ORIGIN=https://jaringobe.cloud`, `COOKIE_SECURE=true` 로
바꾸고 백엔드를 재기동해야 한다. **로컬 개발로 돌아올 때는 반드시 `http://localhost:3000` / `false`
로 되돌린다** — 안 되돌리면 로컬에서 쿠키가 저장되지 않아 로그인이 되지 않는다.

정식 호스팅처(VPS vs Fly.io·Koyeb + Neon 등)는 **릴리즈 시점에 결정**하기로 미뤄두었다.
이관 절차는 [backend-portable-guide.md](./backend-portable-guide.md) 에 정리되어 있다.

### 소셜 로그인·LLM 키가 비어 있다
`.env` 의 `KAKAO_*`/`GOOGLE_*`/`ANTHROPIC_API_KEY` 가 비어 있다(옛 서버와 함께 사라짐).
- 소셜 로그인 불가 → 로그인이 필요한 기능 전체가 막힌다. 각 콘솔에서 재발급 + 콜백 URL 등록 필요
- `ANTHROPIC_API_KEY` 없으면 AI 식단은 mock 모드
